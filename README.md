# todo list backend

## TODO API

- GET /api/todos - get all todos
- POST /api/todos - create a new todo
- DELETE /api/todos/{id} - delete todo by id
- PUT /api/todos - update todo by id

## USERS API

- POST /api/login - authenticate user returns jwt token
- POST /api/register - create a new user in database

## Stack

- Go (Golang) + net/http
- postgresql
- jwt authentication
- kafka
- redis
